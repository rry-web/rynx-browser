RYNX BROWSER

Press e, type an address or search words, and press Enter. q quits.

These are the default keys; Keys shows the ones in force, and they can be changed in keys.conf in the settings folder.

Moving around

h j k lMove the cursor; the view follows
Up / Down, scroll wheelScroll; the cursor stays on screen
PageUp / PageDown, Ctrl+b / Ctrl+fScroll a screen
Ctrl+u / Ctrl+dScroll half a screen
g / G, Home / EndTop / bottom of the page

Links and history

Tab / Shift+TabSelect the next / previous link or form field (where it goes is shown at the bottom)
Enter, clickOpen the link, or use the form field
Backspace, Left, HBack (to where you were on the page)
Right, LForward
rReload
b / BBookmark the page (or remove it) / show bookmarks
sPages you've visited (on that page, x twice clears them)
dDownload the selected link
EscClear a finished download

Forms

Enter on a fieldStart typing; Enter submits, Esc stops typing, Ctrl+u clears
Enter on a box or choiceTick a checkbox, pick an option, or show the next choice
Enter on a buttonSubmit the form

Tabs

n / wNew tab / close tab
t, Ctrl+clickOpen the selected link in a new tab
[ / ]Previous / next tab

Address bar (press e)

EnterGo; words that aren't an address are searched with Marginalia
EscCancel and restore the address
Ctrl+u / Ctrl+kClear / clear and paste
Ctrl+y / Ctrl+vCopy / paste

A Tools: link at the top of a page opens the site's tools as forms. Running one shows exactly what will be sent first: y runs it, n cancels.

Addresses can also be gemini:// or gopher://, and RSS or Atom feeds open as a page of posts.

The search engine (Marginalia, DuckDuckGo or your own), home page and more can be changed in settings (S).

Find on page, copying, and more

/Find on the page; > / < jump between matches, Esc clears
vCopy mode: select with h j k l or the arrow keys, y copies, Esc cancels
UUpdates: what's new, and installing it at the next start
ILoad this page's images
iView the selected image full screen (Esc closes)
TTrack this site: keep a dated snapshot whenever one of its pages changes
ZSnapshots of this page; open one to see the page as it was
AThe Internet Archive's copy of the page (for pages that are gone or blocked)
RReader mode: only the page's main text (R again for the whole page)
Shift+VShow the page source
pSwitch I2P mode on or off, unless settings lock it
SSettings: home page, search engine, I2P lock, history and more
CLet this site keep cookies, so you stay signed in (C again forgets them; Cookies lists them)
